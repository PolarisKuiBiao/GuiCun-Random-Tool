# 👻 鬼村神秘小工具 4.0

一个为《洛克王国·盗版吸血鬼村庄》（简称「鬼村」）设计的**主持人辅助工具**。基于 15 人狼人杀框架，帮助主持人完成身份分配、夜晚行动、投票处决、警长竞选、公开死亡记录与游戏日志等全流程管理。本项目完全由Deepseek生成。

- ✅ 单文件、纯前端，**无需服务器、无需联网**
- ✅ 所有数据保存在浏览器 `localStorage`，刷新 / 关闭后不丢失
- ✅ 三大板块互相独立，主持人数据与玩家数据互不干扰

---

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可使用。

打开后首先看到**主菜单**，三个大按钮对应三大板块，点击进入；每个板块顶部有「🔙 返回菜单」按钮。

---

## 🧩 三大板块

### 🎮 第一板块 · 娱乐功能

| 功能 | 说明 |
| --- | --- |
| 🎲 随机数 | 在指定范围内生成随机整数 |
| 🍀 今日人品 | 输入名字看运气，同一天同一名字结果固定 |
| 🍮 要不要相信果冻 | 随机给出「相信 / 不相信」趣味结论 |
| 🏆 牢冰会赢吗 | 50% 概率回答「该赢了 / 接着输」 |

### 🖥️ 第二板块 · 主持人板块

主持人的核心操作区，包含：

#### 🆔 15人身份分配
- 角色池：**4 普通村民 + 4 吸血鬼 + 6 神职（长老、预言家、女巫、守护者、猎人、丘比特）+ 1 吹笛人**，共 15 人
- 输入 15 位玩家姓名（按座位顺序，空格 / 逗号分隔）
- 随机分配身份，支持按「全部 / 村民 / 吸血鬼 / 神职」切换查看
- 「💾 保存分配」可锁定当前角色，防止刷新后重新洗牌；「🔓 重置」解除锁定

#### 🖥️ 主持人控制台（上帝视角）
- **📊 汇总**：存活人数、情侣、警长、三阵营存活统计、长老剩余生命、神职技能失效提醒
- **⏳ 流程提醒**：游戏时间切换（第 1~7 天 × 白天 / 夜晚）、夜晚行动顺序、吹笛人本晚可施法人数
- **💘 丘比特指定情侣**：选择两人绑定（不可重复），确认后锁定，绑定后死亡联动
- **💀 死亡标记**：只读展示各玩家死因与状态，支持「撤销死亡」「重置所有死亡」
- **夜晚行动**（需切换到「夜晚」）：
  - 🪄 吹笛人施法（奇数天 1 人 / 偶数天 2 人，不能对自己，附已吹奏进度）
  - 🧛 吸血鬼行动（自动列出存活吸血鬼，需 ≥ 人数一半向上取整参与击杀）
  - 🛡️ 守护者行动（每晚守护 1 人，不能连续两晚守护同一人）
  - 👁️ 预言家行动（按姓名 / 序号搜索查验，不能查验自己，显示所属阵营）
  - 🧙 女巫行动（解药 / 毒药各一次、每晚只能用一种，解药需目标未被守护者保护）

#### 🗳️ 投票
- 记录每名存活玩家的投票对象（警长计 2 票，不能投给已死亡玩家）
- **警长竞选**：投票选出警长，自动赋予身份
- **投票处决**：得票最高者被处决
- 投票日志自动记录「谁投给了谁 + 谁弃权 + 结果」

#### 📜 村中日志
- 手动输入 + 各环节一键自动写入
- 「一键写入整夜总结」按 吹笛人 → 吸血鬼 → 守护者 → 预言家 → 女巫 → 当晚死亡 的顺序汇总
- 时间戳采用游戏世界时间（第 X 天白天 / 夜晚）

#### 🎯 骰子工具
- 1d2 / 1d6 / 1d12 / 1d18，支持额外 +N（0~100）

### 👥 第三板块 · 玩家板块

| 功能 | 说明 |
| --- | --- |
| 🔮 玩家推测 | 逐个猜测每位玩家是村民 / 吸血鬼 / 神职（可细分）/ 中立（吹笛人） |
| 👥 玩家视图 | 公开死亡记录：独立时间切换、点击「💀 死亡」选择死因、死亡后可公布真实身份 |

玩家板块与主持人板块**数据完全独立**，互不影响。

## ⚙️ 核心规则实现

- **死因分类**：投票处决、吸血鬼击杀、女巫毒药毒杀、猎人开枪击杀、情侣殉情
- **长老**：被吸血鬼击杀保留一条命；其他死因立即死亡并使神职技能失效
- **猎人**：死亡后可开枪带走一名玩家（可延后手动执行）
- **情侣**：一方死亡，另一方立即殉情；死亡时序决定猎人能否开枪
- **警长**：死亡后弹出移交提示，可延后手动移交

## 💾 数据存储

所有数据通过浏览器 `localStorage` 持久化，主要键如下（供高级用户参考）：

| 键 | 内容 |
| --- | --- |
| `village_assignment_saved` | 身份分配（姓名 + 角色） |
| `village_dead` / `village_death_reasons` / `village_death_times` | 死亡状态、死因、死亡时间 |
| `village_couple` | 情侣（含锁定状态） |
| `village_elder` | 长老生命与神职技能状态 |
| `village_night_actions` | 夜晚行动（吹笛 / 吸血鬼 / 守护者 / 女巫 / 预言家） |
| `village_votes` | 投票与警长 |
| `village_bewitched` | 吹笛人施法名单 |
| `village_log` | 村中日志 |
| `village_game_time` | 主持人板块游戏时间 |
| `village_public_deaths` | 玩家板块公开死亡记录 |
| `village_player_time` | 玩家板块游戏时间 |
| `village_guesses` | 玩家推测 |
| `village_sheriff_transfers` | 警长移交记录 |

> 主持人板块顶部提供「🔄 重置所有内容」按钮，可一键清空主持人板块数据（不影响玩家板块）。

## 🛠️ 技术说明

- 纯 HTML + CSS + JavaScript，无外部依赖
- 逻辑封装在单个 `<script>` 的 IIFE 中，避免污染全局作用域
- 视图切换采用「主菜单 + 三大板块」的显隐式单页结构
- 兼容现代浏览器（Chrome / Edge / Firefox）
